PRUEBA MANUAL DEL BACKEND (en curso)
------------------------------------
Arrancar el servidor (terminal 1, DENTRO de la carpeta del proyecto):
   cd C:\Users\Daniel\Desktop\Web2\Eticket
   npm run build
   npm run lan:demo

Probar (terminal 2, PowerShell; las variables se pierden si cierras la terminal):
   $api = "http://localhost:3000/api"
   $s = New-Object Microsoft.PowerShell.Commands.WebRequestSession
   Invoke-RestMethod "$api/auth/login" -Method Post -ContentType 'application/json' -Body '{"username":"usuario","password":"usuario"}' -WebSession $s

   [OK] Paso 2  health -> ok True
   [OK] Paso 3  login como usuario -> role=applicant
   [  ] Paso 4a crear ticket:
        $t = (Invoke-RestMethod "$api/tickets" -Method Post -ContentType 'application/json' -WebSession $s -Body '{"title":"Prueba backend","category":"Hardware","priority":"Media","description":"Mi primer test"}').ticket
        $t | Select-Object id, title, status, technicianName
   [  ] Paso 4b el solicitante intenta cambiar el estado -> DEBE dar error 403
   [  ] Paso 4c el admin reasigna a Ana (technicianId 2) -> En proceso
   [  ] Paso 4d tecnico agrega seguimiento y marca Resuelta
   [  ] Paso 5  misma prueba desde el navegador en http://localhost:3000

   Nota: evitar tildes/eñes dentro de -Body en PowerShell 5.1.
   Reiniciar datos locales: Ctrl+C, borrar data\tickops.db*, npm run lan:demo
